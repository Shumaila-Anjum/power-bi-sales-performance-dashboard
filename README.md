# Power BI Sales Performance Dashboard

## Overview
An interactive Power BI dashboard designed to analyse sales, customer performance, product categories, regional trends, and order-level details.

## Key Features
- Sales KPIs including Total Sales, Gross Profit and Profit Margin
- Customer ranking using RANKX
- Shipping time analysis
- Month / Year / Fiscal Year switching
- Dynamic trend analysis by Region, Category and Business Type
- Top 10 Customers by Sales
- Sales by Product Subcategory
- YoY Sales Change
- Drill-through Sales Order Details page
- No-data message and last refresh information

## Tools & Skills
- Power BI
- DAX
- Power Query
- Data Modelling
- Data Visualisation
- Business Intelligence

## Key Insights
- Bikes were the strongest-performing product category.
- Road Bikes and Mountain Bikes were major contributors to sales.
- Regional performance varied significantly.
- Customer analysis identified the highest-value customers.
- The dashboard enables users to investigate performance from summary KPIs down to individual sales orders.
