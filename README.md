# 📊 Sales Performance & Customer Analytics Dashboard

> An interactive Power BI solution that transforms sales data into actionable insights across customers, products, regions and business performance.

## 🎯 Project Overview

This project demonstrates an end-to-end Power BI reporting solution designed to help business users understand sales performance, identify high-value customers, analyse product and regional trends, and drill down into individual sales transactions.

The solution combines data modelling, DAX, interactive visualisation and business-focused analysis.

## 🛠️ What I Built

- Executive Sales Performance Dashboard
- Customer Analysis Dashboard
- Detailed Sales Order Drill-through Page
- Insights & Recommendations Page
- Dynamic Year / Fiscal Year / Month analysis
- Dynamic Region / Category / Business Type analysis
- Top 10 Customer ranking
- YoY sales performance analysis
- Interactive slicers and filters
- Last refresh information
- No-data handling for filtered views

## 📈 Key KPIs

- Total Sales
- Total Orders
- Total Quantity
- Gross Profit
- Profit Margin %
- Average Shipping Days
- Total Customers
- Average Sales per Customer
- Top Customer Sales
- YoY Sales Change %

## 💡 Business Questions Answered

The dashboard helps answer questions such as:

- How are overall sales and profitability performing?
- Which product categories generate the most revenue?
- Which regions contribute the most sales?
- Who are the highest-value customers?
- How have sales changed compared with the previous year?
- Which product subcategories drive performance?
- How efficiently are orders being shipped?
- What individual transactions are driving the results?

## 📂 Data

The model includes sales transactions, customers, products, geographical information, sales territories, order dates, shipping dates, quantities and financial measures.

> **Data Privacy:** The original source dataset and assessment files are not publicly shared. This repository showcases the analytical approach, Power BI development, DAX implementation and resulting dashboards.
